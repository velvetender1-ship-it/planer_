# برنامه‌ریز مشاور (نسخهٔ آفلاین / PWA)

## انتشار روی GitHub + Vercel
1. در GitHub یک ریپوی جدید بساز (مثلاً `konkur-planner`) ← «uploading an existing file» ← این ۶ فایل را بکش و Commit کن:
   `index.html` · `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png` · `README.md`
2. در vercel.com ← Add New → Project ← همان ریپو را Import کن ← بدون هیچ تنظیمی Deploy.
3. لینک `*.vercel.app` را روی گوشی باز کن ← Add to Home Screen. بعد از اولین باز شدن، بدون اینترنت هم کار می‌کند.

## داده‌ها
روی هر دستگاه جدا ذخیره می‌شوند. برای انتقال: تنظیمات ← دانلود فایل پشتیبان ← در دستگاه دیگر «بازگردانی از فایل».

## به‌روزرسانی
فایل‌های جدید را در همان ریپو جایگزین کن؛ Vercel خودش منتشر می‌کند. اگر نسخهٔ جدید دیده نشد، اپ را یک‌بار ببند و باز کن.
